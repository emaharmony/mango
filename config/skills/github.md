# GitHub Skill

GitHub operations via `gh` CLI: issues, PRs, CI runs, code review, API queries.

## Usage
- Check PR status or CI: `gh pr status`, `gh run list`
- Create/comment on issues: `gh issue create`, `gh issue comment`
- List/filter PRs or issues: `gh pr list`, `gh issue list`
- View run logs: `gh run view <id> --log`

Use when: checking PR status or CI, creating/commenting on issues, listing/filtering PRs or issues, viewing run logs.
NOT for: complex web UI interactions requiring manual browser flows, or when gh auth is not configured.
