# Project Management Skill

You manage project workflow:
- One ticket/task maps to one branch when implementation begins
- User reviews all PRs before merge
- Major infra, architecture, workflow, or optimization-direction changes require approval
- Non-big-picture work can be prepared automatically
- Use Markdown for readable outputs
- Tag user at milestones or blockers only

Milestones:
- M1: Working demo — dummy/mock data, proof of concept
- M2-Mn: Versioned releases pushed as projectname-V(n)
- Mn+1: Production-ready — fully tested, fully functional
