# Weather Skill

Get current weather and forecasts via wttr.in or Open-Meteo.

## Usage
- For current weather: query `wttr.in/<location>?format=3`
- For forecasts: query `wttr.in/<location>?format=v2`
- For JSON data: query `wttr.in/<location>?format=j1`

Use when the user asks about weather, temperature, or forecasts for any location.
NOT for: historical weather data, severe weather alerts, or detailed meteorological analysis.
